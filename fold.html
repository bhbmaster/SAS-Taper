SAS-Taper · how it works

Choosing the fold

The taper says cut 15.28 mm off a 22 mm film. Nobody has a ruler that good at 6 am. So the tool works out how to fold the film into a simple grid and take whole parts of it instead — and this is how it decides which grid, which parts, and where the blade goes.

# The film folds into a grid: the long (22 mm) side into 1, 2, 3, 4 or 8, the
# short (12.8 mm) side into 1, 2, 3 or 4. Eighths along the length are three
# successive halvings, so they stay reproducible. The width stops at quarters,
# because an eighth of 12.8 mm is 1.6 mm and nobody judges that by eye.
LONG  = [1, 2, 3, 4, 8]
SHORT = [1, 2, 3, 4]


def fraction_cut(want, film_mg, full_mm, wide_mm, tol_mg):
    # want    the dose as a fraction of one whole film, 0 to 1. The film is
    #         an evenly made sheet, so area fraction IS dose fraction.
    # tol_mg  how far out a fold may be and still count as good enough. Pass
    #         the reader's own cutting tolerance: a fold inside it is no worse
    #         than the slip they would make with a ruler.
    pool = []
    for L in LONG:
        for S in SHORT:
            for cells in range(1, L * S + 1):

                # THE SHAPE RULE. `cells` could mean any scattered set of
                # squares, which is useless as an instruction. Splitting it
                # once forces the piece to be whole columns plus a tab off the
                # very next one — a rectangle, or an L, always contiguous.
                columns, tab = divmod(cells, S)

                # CUTS FALL OUT OF THE SHAPE — nothing is searched for here.
                # The middle term is the good one: a tab that runs to the
                # film's own edge needs no cut on that side, because the
                # manufacturer already made it. That is why 5/6 on a 3x2 grid
                # is two strokes and not three.
                if cells == L * S:
                    cuts, pieces = 0, 1
                elif tab == 0:
                    cuts, pieces = 1, 1
                else:
                    cuts = ((1 if columns else 0)
                            + (1 if columns + 1 < L else 0)
                            + 1)
                    pieces = 2 if columns else 1

                # HOW HARD IT IS BY HAND. A stroke across the short axis is
                # 12.8 mm guided by the film's own straight edge; one along
                # the long axis is 22 mm freehand down the middle. Pricing
                # them the same makes a plain half come out as 1x2, which is
                # the wrong instruction — so lengthwise costs more.
                lengthwise = 1 if tab else 0
                d  = (cuts - lengthwise) * 10 + lengthwise * 14
                d += (pieces - 1) * 4
                d += {1:0, 2:0, 3:2, 4:3, 8:6}[L]   # finer = harder
                d += {1:0, 2:2, 3:5, 4:7}[S]        # worse across
                if tab and min(full_mm / L, wide_mm * tab / S) < 2:
                    d += 20                         # too small to hold

                err = abs(cells / (L * S) - want) * film_mg
                pool.append((d, err, L, S, cells, columns, tab, cuts, pieces))

    # THE PICK. Buy simplicity, but only with error you were going to spend
    # anyway. The cap is on the error ITSELF, not a margin added to the best
    # one — added, the two compound, and the chosen fold can land further out
    # than the tolerance the reader actually stated.
    best = min(err for _, err, *_ in pool)
    cap  = max(best, tol_mg)

    # Lowest difficulty wins. The keys after it never decide anything on
    # their own; they are there so ties break the same way every time, which
    # is what holds the drawing still for a reader who changed nothing.
    return min((c for c in pool if c[1] <= cap),
               key=lambda c: (c[0], c[1], c[3], -c[2], c[4]))


# DRAWING IT. There is no second implementation of the geometry: the picture
# reads `columns` and `tab` straight off the result, and the blade lines are
# the same three conditions that produced the cut count above.
cw, rh = W / L, H / S
fill(0, 0, columns * cw, H)              # the whole columns
fill(columns * cw, 0, cw, tab * rh)      # the tab
if columns:         vline(columns * cw)
if columns + 1 < L: vline((columns + 1) * cw)
if tab:             hline(tab * rh, across that column)
01 The target

One number, as a fraction of the film

The ladder hands over a dose in milligrams. Because the film is one evenly made sheet, area fraction is dose fraction — so the dose becomes a single number between 0 and 1, and the film's actual size stops mattering until it is time to draw.

That is the whole input. Everything after this is a search for the closest fraction a person can fold.

The exact cut. One straight line, at a number you would need a steel rule to hit.

02 The search space

Fold the long side into 1, 2, 3, 4 or 8 — the short side into 1, 2, 3 or 4

Eighths along the 22 mm length are three successive halvings, which stay reproducible. The 12.8 mm width stops at quarters, because an eighth of it is 1.6 mm and nobody judges that by eye.

That gives 20 grids, and inside each you can take any whole number of cells. 180 candidates, landing on 54 distinct fractions.

The widest gap anywhere in that ladder is between 1/8 and 5/32, a hair over 3%. So for any target above 1/32 the grid is never more than 0.125 mg away on an 8 mg film — already better than the ±0.18 mg a ruler slip costs you.

All 54 reachable fractions. Taller ticks are the ones a coarse grid can hit. The marker is your target.

03 The shape rule

Whole columns, plus a tab off the next one

This is the constraint that makes the whole thing work. Taking k cells out of a grid could mean any scattered set of them — useless as an instruction. So k is split once:

columns, tab = divmod(cells, short_div)

and the piece is always that many whole columns, plus that many cells of the very next column. A rectangle, or an L. Never scattered, never two separate corners.

One line of arithmetic, and it buys three things at once: the piece is always contiguous, the cut count falls out of it, and the drawing has something simple to draw.

Left: what divmod produces. Right: a set of cells adding to the same fraction that the rule refuses to consider.

04 Counting the cuts

The cut count is not searched for — it falls out of the shape

Given columns and tab, how many strokes the piece needs is fixed. There are only four cases:

# the whole film
cuts = 0
# whole columns only — one stroke across
cuts = 1
# anything with a tab
cuts = (1 if columns else 0)          # left of the tab
     + (1 if columns + 1 < long_div else 0)  # right of it
     + 1                        # the tab itself

The middle term is the one worth noticing. A tab that runs to the film's own edge needs no cut on that side — the manufacturer already made it. That single condition is why 5/6 on a 3×2 grid is two strokes and not three, and it is why the most common fold in a real taper is also one of the cheapest.

The four shapes, with the strokes you actually make picked out in red. Fold lines are dashed; they cost nothing.

05 Scoring by hand-difficulty

Not every cut is the same cut

Two candidates can both be "one cut" and be completely different jobs. A stroke across the short axis is 12.8 mm guided by the film's own straight edge. A stroke along the long axis is 22 mm freehand down the middle.

d  = crosswise × 10
   + lengthwise × 14
   + (pieces − 1) × 4

# a finer fold is a harder judgement
d += {1:0, 2:0, 3:2, 4:3, 8:6}[long_div]
# and worse still across the narrow side
d += {1:0, 2:2, 3:5, 4:7}[short_div]
# a tab under 2 mm is not a thing fingers do
d += 20 if tab_mm < 2

Thirds score worse than halves because halves come from folding and thirds come from judgement. The short axis scores worse than the long one because it has less room to be wrong in. And a tab under 2 mm is not something fingers do, whatever the arithmetic says.

06 Picking one

Buy simplicity, but only with error you were going to spend anyway

The tool already asks how accurately you can cut. Half a millimetre is realistic, and on 8 mg film that is ±0.18 mg of dose — a slip you make whether you fold or measure.

So any fold inside that band is no worse than measuring, and among those the simplest one is the better instruction:

cap  = max(best_error, tolerance)
pool = [c for c in candidates
        if c.error <= cap]
pick = min(pool, key=(difficulty, error,
                            short_div, −long_div, cells))

The last three keys never decide anything on their own — they are there so that ties break the same way every time. The same target always gives the same fold, so the drawing never moves under a reader who has changed nothing.

The tolerance band, every candidate inside it, and the one that wins. Filled is the pick; hollow are the folds it beat.

07 Drawing it

The picture is built from the same two numbers

There is no second implementation of the geometry. The drawing reads columns and tab straight off the result:

# the piece you swallow
rect(0, 0, columns × cw, H)          # the whole columns
rect(columns × cw, 0, cw, tab × rh)  # the tab

# the strokes — the same three conditions
# that produced the cut count
if columns:
    vline(columns × cw)
if columns + 1 < long_div:
    vline((columns + 1) × cw)
if tab:
    hline(tab × rh, across that column)

Because the count and the picture come from one place, they cannot disagree — and the test suite checks that anyway: the filled area must be the fraction the caption claims, and the number of red lines must be the number of cuts the words promise.

Two things it got wrong first

Both were found by drawing it before shipping it

A plain half came out lengthwise

Both 2×1 and 1×2 are exactly half and both are "one cut", so the tie-break decided — and it picked a 22 mm freehand stroke down the middle of the film over a 12.8 mm one against its own edge. Fixed by pricing the two kinds of stroke differently, which is why the ×14 term exists.

The tolerance compounded

Written as best + tolerance the band floats upward: a candidate can be inside it while sitting further out than the tolerance the reader actually stated. On cycle 2 of the default run that chose a fold 0.22 mg off while claiming to respect ±0.18. The cap has to be on the error itself — max(best, tolerance).

And one thing that fell out for free

In the tool's linear cut mode the dose drops by the same amount every cycle, so the sequence of targets is 5/6, 2/3, 1/2, 1/3, 1/6 — every one of them a fraction this grid hits exactly. A linear taper can be cut from the first day to the last without measuring anything. Nobody designed that; it is just what happens when a constant step meets a grid of simple fractions.
